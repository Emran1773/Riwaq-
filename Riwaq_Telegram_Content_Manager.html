دليل ربط Telegram Bot API

تنبيه أمني هام: لحماية قنواتك من الاختراق، يتم حفظ المنشورات داخل متصفحك بشكل آمن عبر IndexedDB. للنشر التلقائي المباشر عبر السيرفر يتم استخدام API آمن.

خطوات إعداد البوت والنشر التلقائي:

  1. ابحث عن @BotFather في تيليجرام وأنشئ بوت جديد باستخدام الأمر /newbot.
  2. انسخ توكن البوت الخاص بك (API Token).
  3. قم بزيادة صلاحيات البوت وأضفه كـ مشرف (Administrator) في القنوات المستهدفة مع تفعيل صلاحية Publish Messages.
  4. استخدم خيار «تصدير النسخة الاحتياطية» في قسم الأرشيف لتمرير البيانات المجدولة لـ Webhook أو سكريبت خادم آمن.
